O Sistema de Avaliação e Gerenciamento é uma aplicação desktop desenvolvida em Python utilizando a biblioteca Tkinter. O objetivo do sistema é permitir que clientes registrem avaliações sobre uma loja e que funcionários autorizados possam visualizar e gerenciar essas informações.

O sistema possui uma tela de avaliação, onde o usuário pode escolher uma nota de 1 a 5 estrelas por meio de emojis e escrever um comentário sobre sua experiência. Após o envio, o feedback é armazenado no sistema.

Também existe uma tela de login, responsável por verificar o usuário e a senha cadastrados. Funcionários desligados não podem acessar a área administrativa.

Após o login, o funcionário pode acessar um painel administrativo, onde é possível visualizar os feedbacks recebidos, navegar entre eles, marcar avaliações como lidas e excluir feedbacks.

O sistema também possui uma tela de gerenciamento de funcionários, apresentando informações como nome, tempo de empresa, salário e status do funcionário. Os diferentes status são identificados por cores, facilitando a visualização.

A aplicação foi organizada utilizando diferentes classes e telas, permitindo uma melhor separação das funcionalidades e facilitando futuras alterações e melhorias. O projeto utiliza uma estrutura de dados em Python para armazenar temporariamente funcionários e feedbacks durante a execução do programa.
